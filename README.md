# Adis & Ratna — A Month in Messages 💕

A romantic Instagram-Stories-style web experience built from your WhatsApp chat data.

## How to deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `our-story`)
2. Upload `index.html` to the root of the repo
3. Create an `assets/` folder and add your photos:
   - `assets/image-1.jpg` — Cover photo (full portrait, shown as hero)
   - `assets/image-2.jpg` — Photo grid (top-left)
   - `assets/image-3.jpg` — Photo grid (top-right)
   - `assets/image-4.jpg` — Photo grid (middle-left)
   - `assets/image-5.jpg` — Photo grid (middle-right)
   - `assets/image-6.jpg` — Photo grid (bottom banner + letter background)
4. Go to **Settings → Pages → Branch: main → Save**
5. Your site will be live at `https://yourusername.github.io/our-story`

## Navigation
- **Click right side** → next story
- **Click left side** → previous story
- **Swipe left/right** → navigate (mobile)
- **Arrow keys** → navigate (desktop)
- Stories auto-advance every 9 seconds
